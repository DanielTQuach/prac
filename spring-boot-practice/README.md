# Spring Boot Practice

A minimal Spring Boot app with one REST controller.

## Run

From this folder (requires Java 21+):

```bash
./mvnw spring-boot:run
```

On Windows:

```powershell
.\mvnw.cmd spring-boot:run
```

## Try it

- http://localhost:8080/
- http://localhost:8080/hello?name=Spring

## Test

```bash
./mvnw test
```
